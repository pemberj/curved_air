# curved_air

# interferograms

This part of the `curved_air` package contains code to load and visualise interferogram data files from Fisba and Zygo interferometers, as well as grid files compatible with OpticStudio Zemax.

The data can be processed in various ways (re-sampling, removal of zero data, correction by beft-fit forms, etc.) and converted to a format suitable for import into Zemax as either phase or surface sag grid data.
